# Keputusan metodologis

Label: **literatur** = mengikuti definisi sumber yang dirujuk; **operasionalisasi penelitian** = keputusan implementasi/penelitian ini (bukan definisi sumber). Parameter numerik dan labelnya juga ada di `config/parameters.json`. Sumber rancangan: `docs/PHASE3A…6A_DESIGN.md`.
Skor korelasi bukan probabilitas dan bukan bukti kausal; tidak ada dokumen di repositori ini yang menyatakannya demikian.

## Patch v2 (sebelum run LLM final)
Dasar: run v1 (24 laporan model lokal, `results/llm_v1_prapatch`) menunjukkan 19/24 laporan terpotong pada 500 token, Qwen2.5-1.5B hampir tidak mengutip `[Exx]`, TinyLlama menyalin prompt, Qwen2.5-0.5B mengarang angka, dan token nyata ≈ 1,55x (Qwen) / 1,8x (TinyLlama) perkiraan karakter/4. Hasil v1 diarsipkan dan **tidak dicampur** dengan hasil v2.
